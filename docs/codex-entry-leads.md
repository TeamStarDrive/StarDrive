An entry that opens on a `<color=Caption>` heading hands the reader a rule before saying what the topic is for. The fix is one to three plain sentences at the top, before the first heading: what this is and why the player cares, no numbers. Adding one is purely additive: no already fact-checked sentence moves, so nothing needs re-verifying. Keep the lead claim-free where you can, and check it against the code like any other entry where you cannot.

A second, optional pass is worth doing once the leads are in: move per-ship-type variants, exceptions and interactions out of the opening paragraph, and let the shape vary between entries, because uniform structure is what reads as machine-written. That pass does move verified text, so re-read whatever you move.
